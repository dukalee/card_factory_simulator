Card Factory Simulator — UI 시안

1차 시안

A. SCADA 관제실

어두운 HMI 톤. 공정 흐름도 + 컨베이어, 알람 패널, E-STOP

 B. 안돈 / 디지털 트윈

밝은 톤. 안돈 타워, 링 게이지 설비 카드, 컨베이어 위 카드

 C. MES 대시보드

KPI 중심. OEE/불량률, 설비 테이블, 추이 차트

A + B 혼합 시안

혼합 1. 다크 HMI + 링 게이지

A의 구조에 B의 안돈 타워·링 게이지·상태 칩을 이식

 혼합 2. 라이트 관제실

B의 밝은 톤에 A의 우측 알람/정비 패널과 이벤트 로그

 혼합 3. 투톤

상단 다크 공정 라인 + 하단 라이트 정보 패널 3분할

 혼합 4. 좌측 컨트롤 레일

안돈·START/STOP·E-STOP을 좌측 레일에 고정, 하단 알람 티커

 혼합 5. 공장 바닥 뷰 + 글래스

원근감 있는 바닥 위 설비 + 토스트 알람 + 정비 서랍

카드 디자인 (A방향: 일러스트 원화 + 코드 프레임)

카드 시안 6종

타입별 프레임 + SVG 임시 원화. 생성한 원화를 끌어다 놓으면 교체 미리보기, 홀로/커팅 이탈 토글

 원화 프롬프트 시트

이미지 생성 AI용 공통 스타일 + 카드별 프롬프트, 제작 규격, 복사 버튼

카드 생산 · 검수 박스 디자인

검수 1. 좌 목록 · 우 상세

기존 구조를 다듬은 안: 상단 KPI 칩, 좌측 썸네일 그리드, 우측 큰 카드와 합격/불량 버튼

검수 2. 검수대 + 필름스트립

큰 카드를 가운데 놓고 좌우에 합격/불량 대형 버튼, 아래에는 컨베이어를 따라 흐르는 카드 줄

검수 3. MES 표 + 인스펙터

표 형태 목록(상태 뱃지)과 우측 인스펙터. 많은 카드를 빠르게 훑는 데 유리

검수 4. 다크 칸반 보드

미검수 / 합격 / 불량 3열. 카드를 누르면 상단 검수 바에서 판정하면 해당 열로 이동

검수 5. 확대경 + 체크리스트

카드를 크게 확대해 보며 항목(인쇄 · 홀로 · 로고 · 커팅)을 체크한 뒤 판정. 한 장씩 집중해서 검사하는 흐름

검수 6. 2+5 합본

검수대(큰 카드 + 좌우 판정 버튼) + 확대경 체크리스트 + 하단 필름스트립

타이틀 화면 디자인

타이틀 1. 네온 그리드

어두운 사이버 그리드 바닥 + 네온 타이틀. 레트로 아케이드 느낌

타이틀 2. 컨베이어 공장 라인

화면 아래로 카드가 컨베이어를 타고 흐르며 4개 머신을 지나가는 애니메이션

타이틀 3. 카드 쇼케이스

부채꼴로 펼쳐진 6종 카드 위에 타이틀. 카드 게임 같은 화려한 첫인상

타이틀 4. 관제실 HUD

좌측 임무 브리핑 + 우측 시스템 상태 패널. 게임의 SCADA 관제 콘셉트와 일치

타이틀 5. 라이트 홀로그램

밝은 파스텔 배경 + 유리 카드 패널 + 홀로그램 무지개 타이틀. 가볍고 친근한 인상

타이틀 화면 · 컨베이어 안(2번) 발전형

타이틀 2-A. 카드가 완성되는 라인

컨베이어 위 빈 카드가 INK→HOLO→LOGO→CUT 머신을 지날 때마다 색이 입혀지고, 홀로·로고가 붙고, 완성되는 애니메이션

타이틀 2-B. 투시 공장 라인

컨베이어가 화면 깊숙이 뻗어 있고, 카드가 먼 곳에서 앞으로 다가오며 머신 게이트를 통과. 영화 타이틀 같은 깊이감

타이틀 2-C. 스테이션 미리보기

실제 게임 화면의 머신 카드 4개와 컨베이어를 그대로 가져와 타이틀에 배치. 시작하면 보게 될 화면을 예고하는 안
